# GitHub Issue Creation Checklist

Create these seven issues and initially place all of them in **New issues**:

1. Set up the development environment
2. Read an account from the service
3. Update an account in the service
4. Delete an account from the service
5. List all accounts in the service
6. Containerize the microservice using Docker
7. Deploy the Docker image to Kubernetes

Copy the matching story from [AGILE_PLAN.md](AGILE_PLAN.md) into each issue body. Then follow the triage, labels, ranking, and sprint instructions in that file.
