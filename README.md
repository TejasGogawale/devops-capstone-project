# devops-capstone-project

A customer accounts microservice planning capstone for Agile and DevOps. The service manages customer accounts for an e-commerce website and is planned to support creating, reading, updating, deleting, and listing customer accounts through a REST API.

## Project scope
- Plan development environment setup.
- Add REST API capabilities to read, update, delete, and list accounts.
- Containerize the microservice with Docker.
- Plan deployment of the Docker image to Kubernetes.
